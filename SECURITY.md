# Security reports

Please do not disclose credentials, room access tokens, or an exploitable vulnerability in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/zicojiao/trick-or-take/security/advisories/new) for this repository. Include affected files or endpoints, reproduction steps, impact, and a minimal proof of concept with test data. Avoid sending production user data.

This project is maintained on a best-effort basis and does not promise a response SLA. For a fork, operators are responsible for access controls, provider credentials, rate limits, data retention and updates.
